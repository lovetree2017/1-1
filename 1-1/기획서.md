# 영화 티어리스트 웹페이지 기획서

---

## 1. 누가 쓰나
- 영화 애호가 본인과 친구들

---

## 2. 무엇을 하려고
- 영화를 S / A / B / C 티어로 분류하고 친구들과 공유하기 위해

---

## 3. 화면과 동작

**레이아웃**
- 위아래형 (위: 티어 행, 아래: 미배치 영화 목록)

**영화 카드**
- 제목만 표시

**배치 방식**
- 드래그 앤 드롭
- 버튼 클릭

**영화 관리**
- 영화 추가 가능
- 영화 삭제 가능

**공유**
- 이미지로 저장 버튼 제공

**디자인**
- 밝고 깔끔한 화이트 테마

---

## 4. 필요한 자료

**초기 영화 목록 (8편)**

| 번호 | 제목 |
|------|------|
| 1 | 기생충 |
| 2 | 인터스텔라 |
| 3 | 라라랜드 |

| 5 | 어벤져스: 엔드게임 |

| 7 | 타이타닉 |

---

## 5. 완성 기준

- [v] S / A / B / C 티어 행이 화면에 표시된다
- [v] 드래그 앤 드롭으로 영화를 티어에 배치할 수 있다
- [v] 버튼 클릭으로 영화를 티어에 배치할 수 있다
- [v] 영화를 추가할 수 있다
- [v] 영화를 삭제할 수 있다
- [v] 배치 결과가 브라우저를 닫아도 유지된다
- [v] 이미지로 저장 버튼이 동작한다
- [v] 초기 영화 8편이 미배치 상태로 시작된다
